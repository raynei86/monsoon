* Monsoon 

My renewed attempt at writing a chess library.

It's decently fast, with ~perft~ of depth 6 taking about 8 seconds to
run on my laptop. That's about 26x faster than the 210 seconds I got
with [[https://github.com/niklasf/python-chess][python chess]], and almost on par with my [[https://github.com/raynei86/nimsoon][Nim chess library]].

* Setup

Dependencies (`iterate`, `serapeum`, `alexandria`, plus `rove` for the
test suite) are resolved from quicklisp. The project is developed with
[[https://github.com/roswell/roswell][Roswell]].

Link the project into ASDF's source location so quicklisp can find it:

#+begin_src sh
  mkdir -p ~/common-lisp
  ln -s "$PWD" ~/common-lisp/monsoon
#+end_src

* Running tests

#+begin_src sh
  ros run -e '(asdf:test-system :monsoon)'
#+end_src

Or from a REPL:

#+begin_src lisp
  (asdf:test-system :monsoon)
#+end_src
